Multiple Servers

A blog can post the same octothorpes to more than one server. Each server keeps its own independent index.

BACKLINKS

A page can register its octothorpes with more than one server at once. Each server then maintains its own independent index, and clients can query whichever server they want — or all of them — to get a view of what’s been posted.

The blog at octothorpes.bearblog.dev posts to two servers: the main octothorp.es and a separate bearblog.octothorp.es instance. Below are the same blog as seen by each server, fetched live.
